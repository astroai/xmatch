## 2024-05-24 - Pandas select_dtypes overhead and Pandas4Warning
**Learning:** In Pandas, identifying object columns by iterating and checking `df[col].dtype` is very slow. However, using the standard vectorized replacement `df.select_dtypes(include=['object'])` triggers a `Pandas4Warning` in newer Pandas versions due to changes in string handling (deprecation of implicitly including strings as objects). Furthermore, `select_dtypes` still has noticeable overhead compared to direct underlying boolean arrays.
**Action:** Use direct boolean array indexing on the columns attribute: `df.columns[df.dtypes == object]`. This completely avoids the `Pandas4Warning` about string behavior, scales extremely well on high-column datasets, and provides ~70x speedup over iterative property checks.
